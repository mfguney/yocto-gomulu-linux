- [BitBake User Manual](https://docs.yoctoproject.org/bitbake/): sözdizimi ve operatörler (Bölüm 5)

- [Migration notes for 6.0 (wrynose)](https://docs.yoctoproject.org/migration-guides/migration-6.0.html)

## Türkçe

Yocto Project üzerine Türkçe kaynaklar oldukça sınırlıdır. Gömülü Linux'a genel giriş için C ve Sistem
Programcıları Derneği'nin (CSD) gömülü Linux kurs notları GitHub'da bulunabilir. Bilinen başka Türkçe
kaynakların bu listeye eklenmesi rica olunur.
